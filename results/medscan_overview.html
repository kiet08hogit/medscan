MedScan is ready to run locally

A working OpenCV + OCR research project that compares preprocessing methods on medication packaging images, then looks up confirmed names in openFDA.

Verified in this environment

  • 16/16 unit tests passed (pytest -q)
  • Tesseract OCR smoke test read synthetic text Ibuprofen 200 mg
  • openFDA returned a real ibuprofen label
  • evaluation.py correctly refuses to invent metrics when no dataset images exist

How the pipeline works

Question this diagram answers: what happens from image to FDA fields?

Low-confidence or ambiguous matches are rejected instead of guessed. FDA lookup runs only after the user confirms a candidate in the Streamlit UI.

What you do next

  1. cd MedScan && source .venv/bin/activate && streamlit run app.py
  2. Photograph packaging under the six labeled conditions into dataset/images/
  3. Fill dataset/ground_truth.csv
  4. Run python evaluation.py to write real metrics + graphs

Deliberately left empty: experimental result numbers (no fabricated scores), and personal prescription photos (gitignored by design).
